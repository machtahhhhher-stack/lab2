**Тема:** регулярные выражения, unit-тестирование

## Что умеет программа

- проверяет введённые с клавиатуры значения: цвет это или нет;
- находит цвета во введённом тексте, в файле (CSS, HTML, TXT) и на веб-странице по ссылке;
- показывает каждый цвет в полной записи и в виде `rgb()` / `rgba()`, считает повторы;
- сохраняет результат поиска в файл.

Поддерживаются записи `#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA` в любом регистре.

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Тесты

```
python -m unittest discover -s tests -t .
```

Покрытие кода тестами (нужен пакет `coverage`):

```
python -m coverage run --source=hexcolors,main -m unittest discover -s tests -t .
python -m coverage report -m
```
